A simple trace tool

The old borders have no data to download: they have to be drawn. The trace tool lays a public-domain map over ours, lines the two up by eye, then lets you click round a region. The points are kept as longitude and latitude, smoothed into friendly rounded outlines, and exported as a file to commit. (Lesson 03, the moments, comes after: the tool first, so the shapes can be drawn while the story is written.)

1. Lining up an old map

  • The four reference maps (reference-maps/, see its SOURCES.md) are scans of atlases from 1865–1911, each in its own projection. Ours is a Lambert conic. They will never match exactly, and for rough, child-sized shapes they don't need to.
  • So the alignment is the simplest that works: move (drag), size (scroll, about the cursor, so the place under it stays put), stretch (taller or wider) and rotate. Line up the Danube, the coast and the Carpathian bend, the things that haven't moved in 2,000 years, and the borders follow.
  • The alignment is kept in frame widths, not pixels: the picture's centre, from the frame's corner, and its width, as fractions of the frame's width. Resize the window and the picture stays lined up, because the frame is refitted the same way (lesson 02's trick).
  • Opacity, and the Multiply blend, let the old map's lines show through over the satellite picture.

2. Points in degrees, not pixels

click (x, y)  →  projection.invert([x, y])  →  [lon, lat]   // stored
[lon, lat]    →  projection([lon, lat])      →  (x, y)       // drawn, at any size
  • A shape is its control points, the ones you clicked, in [lon, lat] (4 decimals, about 10 m). Everything else is computed from them, so dragging a point redraws the outline.
  • Click to add points; click the first point (or Enter) to close the shape. On a closed shape a click puts a point into the nearest edge, and a right-click removes one.
  • Kept in localStorage while you work, so a reload loses nothing.

3. Smoothing: a curve through the clicks

  • A handful of clicks would make a jagged polygon. Smoothing draws a Catmull-Rom spline through them: a curve that passes through every point, bending gently between them. A B-spline would be smoother still but misses the points, so a border wouldn't go where you put it.
  • The centripetal kind: the curve's speed between two points depends on the square root of their distance, which stops it looping or overshooting where two clicks are close together.
  • It is computed in our projection at a fixed size, not in raw degrees: at 46° N a degree of longitude is only 0.7 times as long as a degree of latitude, and smoothing in degrees would squash the curves sideways. Eight points are sampled between each pair of clicks.
  • Smooth can be turned off per shape, for the straight edges of a modern border.

4. The file: GeoJSON

  • Export writes shapes.geo.json, a GeoJSON FeatureCollection: the smoothed outline as each feature's polygon (3 decimals, about 100 m), so the player and any GIS tool can read it directly, and the control points in its properties, so Import can bring a shape back to edit.
  • One trap: d3-geo works on the sphere, where a ring's direction says which side is inside. Drawn the other way round, a polygon is the whole world except the shape. The tool checks the area (geoArea) and turns any ring bigger than a hemisphere round.
  • Each shape remembers which reference map it was traced from, for the credits.

5. A dev tool

  • The reference maps are served by ng serve only (the development configuration's assets in angular.json), so they never ship. Open… loads any other image from your disk.
  • The Trace link shows only in development (isDevMode()).
  • The panel shares the randomize-studio look with the backdrop tuner: styles/_studio.scss.

Review checklist

  • Pick the Spruner map, Align: drag and scroll until the Danube and the coast match; resize the window, it stays matched
  • Draw round Roman Dacia: the outline is rounded, passes through every click, and closes on the first point
  • Drag a point, add one on an edge, right-click one away; reload: everything is still there
  • Export, delete the shape, Import: it comes back, editable
  • The exported polygon fills the region, not the rest of the world
